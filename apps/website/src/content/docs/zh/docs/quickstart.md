这一页走完最初的十五分钟：接上模型、看看这个智能体到底会做什么，以及接下来该往哪走。前提是八千代已经[装好](/zh/docs/install/)并在运行。

## 1. 接上供应商

首次启动时，引导浮层会按顺序问你三件事：

1. **供应商** —— 从内置预设里挑一个（Anthropic、OpenAI、Gemini、DeepSeek、Moonshot、OpenRouter、Ollama，以及另外十几个）。预设会替你填好 API 类型和 base URL。
2. **API key** —— 粘贴进去。它会加密存入本机的供应商凭据库，并且不参与同步。
3. **模型** —— 选一个新对话默认用的。

如果你跳过了浮层，同样的东西在 **设置 → 供应商** 里。命令行版本：

```bash
yachiyo provider list
yachiyo provider models anthropic       # API 那边提供了什么
yachiyo provider set-default anthropic --model <model-name>
```

跑本地模型？选 **Ollama** 预设 —— 它指向 `http://localhost:11434/v1`，不需要 key。

## 2. 发一条消息

新建线程然后开始打字。第一轮对话里有几个地方值得注意：

- 第一条回复落地后，线程标题会自己写好。
- 输入框里的模型选择器是**按消息**切换的，不是按应用。用便宜的模型起草，把某一个问题升级给大模型。
- 回复还在流式输出时你就可以继续打字。回车是干预正在进行的回复还是排队一条后续消息，在 **设置 → 通用 → 行为** 里设定。

## 3. 给它一个工作区

聊天是无聊的那一半。八千代真正有用，是在它有一个目录可以干活的时候。

打开 **设置 → 能力 → 工作区**，添加一个文件夹 —— 一个项目仓库、一个笔记目录、一个草稿文件夹都行。然后把这个工作区挂到某个线程上，提一个具体的要求：

> 看一下这个文件夹里的 CSV，告诉我哪些文件的列名不一致。

这个智能体可以读文件、改文件、搜索、跑 shell 命令，也能上网。它改动的每个文件都有快照，所以一次运行结束后你拿到的是一份可以复核的 diff，而不是一句「我做对了」的保证。

见[工作区与文件](/zh/docs/guides/workspace/)。

## 4. 试一个技能

技能是一些 Markdown 指令，智能体按需加载。八千代自带一批 —— 浏览器自动化、PDF/DOCX/XLSX 处理、Zotero、终端控制，以及教它认识自己命令行的 `yachiyo-help`。

问一个需要用到技能的问题：

> 你到底能干什么？先看看你的 help 技能。

在 **设置 → 能力 → 技能** 里逐个启用或停用。想自己写的话，一个目录加一个 `SKILL.md` 就够了 —— 见[技能](/zh/docs/guides/skills/)。

## 5. 别再手动配它了

这是最值得尽早养成的习惯，也是大多数人最慢才捡起来的那个。

八千代默认启用了 `yachiyo-help` —— 一个记录了它自己的命令行、配置文件和安装流程的技能 —— 而且它有你机器的 shell 权限。也就是说它可以自我管理。以下这些你都不必手动做：

| 与其                    | 不如说                                                  |
| ----------------------- | ------------------------------------------------------- |
| 手写 LaunchAgent plist  | 「开机登录时自动启动你自己。」                          |
| 手动修 `PATH`           | 「终端里找不到 `yachiyo` 命令，修一下。」               |
| 拼一段定时任务 JSON     | 「每个工作日早上 8 点，看一下我的收件箱笔记并做摘要。」 |
| 在供应商模型列表里翻找  | 「OpenAI 那边我能用哪些模型？把最便宜的三个开了。」     |
| 从零手写一个 `SKILL.md` | 「给我做一个写发布说明的技能。」                        |
| 为了一个设置项去翻文档  | 「工具模型是干什么的？我该设成什么？」                  |

手动的路径全都还在，这份文档也保留了它们 —— 你应该能看清自己机器上到底发生了什么。但这些页面主要是*出问题时*的参考，或者你想把它写进脚本时的参考。默认的交互界面是一句话。

## 6. 把它接到外面的世界

基础跑通之后，下面这些才让八千代从一个标签页变成一个常驻的东西：

- **[定时任务](/zh/docs/guides/schedules/)** —— 按 cron 表达式或在指定时间执行一段提示词。早报、夜间巡检、一次性提醒。
- **[频道](/zh/docs/guides/channels/)** —— 接上 Telegram、Discord 或 QQ，让同一个助手、带着同一份记忆，在你手机上回话。
- **[编码智能体](/zh/docs/guides/coding-agents/)** —— 把实现工作交给子智能体或外部编码智能体，结果回到线程里。
- **[记忆与人格](/zh/docs/guides/memory-and-persona/)** —— `SOUL.md` 和 `USER.md` 决定它在每个线程和频道里的表现。

## 你的数据在哪

| 是什么           | 在哪                                              |
| ---------------- | ------------------------------------------------- |
| 设置和供应商配置 | `~/.yachiyo/config.toml`                          |
| 模型供应商凭据   | `~/.yachiyo/provider-credentials.enc`（本机加密） |
| 机器人 token     | `~/.yachiyo/channels.toml`                        |
| 线程与消息       | `~/.yachiyo/yachiyo.sqlite`                       |
| 人格与档案       | `~/.yachiyo/SOUL.md`、`~/.yachiyo/USER.md`        |
| 技能             | `~/.yachiyo/skills/`                              |

没有托管后端，没有遥测。唯一的网络请求是发给你自己配置的供应商，以及你让它去读的网页。
