---
title: 远程访问
description: 将 iPhone 与八千代配对，选择连接方式，并在离开电脑后继续桌面上的对话。
---

Yachiyo Remote 让你在 iPhone 上查看并继续电脑上的对话。模型请求和工具仍在配对的电脑上运行，工作区文件也留在电脑上。请保持八千代运行，并让电脑保持唤醒和联网。

你可以查看回复和工具调用、发送消息与附件、追加指令或停止运行、回答提问、审批计划，也可以选择电脑上的工作区和模型来新建对话。

你需要桌面版八千代，以及安装了 Yachiyo Remote 的 iPhone。手机需要 iOS 17 或更新版本。请及时更新两端应用。在电脑的 **设置 → 远程** 中配置；远程访问不依赖[同步](/zh/docs/guides/sync/)功能。

通过 [TestFlight 公开测试](https://testflight.apple.com/join/HnVRy31b)安装 iPhone 客户端。先在 iPhone 上安装 TestFlight，再打开这个链接安装八千代。需要 Connect 邀请码时，请到[邀请申请 issue](https://github.com/ringotypowriter/yachiyo/issues/78)留言，注明电脑使用的平台，并留下接收邀请码的联系邮箱。

## 连接并配对

如果已有 Yachiyo Connect 邀请码，选择 **Yachiyo Connect（推荐）**。它不需要你准备域名、安装 `cloudflared`，也不需要 iCloud 地址恢复文件夹。没有邀请码时，可以使用下面的[其他连接方式](#其他连接方式)。

1. 在电脑打开 **设置 → 远程**。输入**邀请码**，点击**激活 Connect**。
2. 将连接方式设为 **Yachiyo Connect（推荐）**，开启**远程访问**，保存设置。
3. 等待显示**已连接 Yachiyo Connect**，在**配对手机**一行点击**显示二维码**。
4. 打开 iPhone 上的 Yachiyo Remote 扫码。需要添加另一台电脑时，在手机的 **Settings → Devices → Add device**（设置 → 设备 → 添加设备）中操作。
5. 打开一段对话并发送消息。再用手机蜂窝网络试一次，确认离开电脑所在网络后仍能连接。

相机无法扫码时，在电脑上点击**复制链接**，再在 iPhone 上选择 **Paste pairing link**（粘贴配对链接）。需要复制完整的配对链接，不能使用服务地址。二维码和链接在五分钟后失效，只能使用一次。生成新二维码或链接后，之前尚未使用的那一个会立即失效。

:::caution[不要公开配对码]
配对码会授权手机访问电脑上的助手和工具。只把它交给自己的手机。不要把二维码或配对链接放进公开聊天、截图或 issue。
:::

## 其他连接方式

| 方式             | 需要准备什么                                       | 地址如何变化                                     |
| ---------------- | -------------------------------------------------- | ------------------------------------------------ |
| **快速隧道**     | macOS 或 Windows 上的 `cloudflared`                | 使用临时 Cloudflare 地址，隧道进程重启后可能变化 |
| **命名隧道**     | `cloudflared`、Cloudflare 账号，以及指向隧道的域名 | 使用你自己的固定域名                             |
| **外部连接地址** | 自行管理的 HTTPS 反向代理或隧道                    | 使用你填写的公网地址                             |
| **局域网**       | 两台设备处于同一个可信网络                         | 使用电脑的局域网地址；离开这个网络后不可用       |

### Cloudflare 隧道

在 macOS 上，可以直接告诉八千代：

> 帮我用快速隧道配置 iPhone 远程访问，并设置自动恢复。

内置 `yachiyo-remote` 技能会检查 `cloudflared`、准备自动恢复守护进程，并让隧道使用 HTTP/2。它也会检查 iCloud 地址恢复是否可用。隧道由 macOS LaunchAgent 托管，但八千代本身仍须运行，才能提供对话服务。

手动配置见 [`yachiyo remote`](/zh/docs/cli/remote/)。只在设置里选择隧道，不会安装 `cloudflared` 或创建隧道。配置完成后，等到地址出现，再点击**显示二维码**配对。

Windows 需要安装 `cloudflared.exe`，并让应用能通过 `PATH` 找到它。安装后重启八千代。隧道进程由应用管理；关闭最后一个窗口会退出应用，同时停止隧道。Windows 不支持 iCloud 地址恢复。如果不想在快速隧道地址变化后重新配对，可以使用命名隧道或固定的外部地址。

Linux 桌面版处于实验阶段，不会替你管理 Cloudflare 隧道。请使用 Yachiyo Connect 或自行管理的外部连接地址。远程访问还需要加密凭据和已解锁的系统密钥存储；桌面应用使用明文凭据模式时，远程访问不可用。

### 外部连接地址与局域网

使用自己管理的反向代理或隧道时：

1. 将 `/remote/v1` 的 WebSocket 请求转发到运行八千代的电脑上的 `http://127.0.0.1:47831`，保留 WebSocket Upgrade 请求头。如果改过远程端口，请使用实际端口。
2. 在 **设置 → 远程** 中选择**外部连接地址**。填写公网 HTTPS 地址，例如 `https://remote.example.com`，或以 `/remote/v1` 结尾的完整 WSS 地址。
3. 开启**远程访问**并保存，然后配对手机。

代理和八千代在同一台电脑时，保留回环地址监听。代理在另一台主机时，开启**局域网**，并在防火墙里只允许代理主机访问该端口。公网入口使用 HTTPS/WSS。

如果只需要局域网访问，选择**外部连接地址**，将**公网地址**留空，并开启**局域网**。开启远程访问并保存后，在同一网络里配对。局域网访问也可以与公网连接方式同时启用。

## 地址变化后重新连接

快速隧道进程每次重启都可能获得新地址。在 macOS 上，八千代可以把新地址加密后写入 iCloud 云盘，让手机重新找到电脑。这与八千代的同步功能分开工作。

1. 在 Mac 和 iPhone 上使用同一个 Apple 账号，开启 iCloud 云盘。
2. 在 iPhone 的 Yachiyo Remote 中打开 **Settings → Address recovery → Yachiyo recovery folder**（设置 → 地址恢复 → Yachiyo 恢复文件夹）。
3. 选择与 Mac 共享的 **iCloud 云盘 → 文稿 → Yachiyo** 文件夹。

配对和聊天不强制要求这个文件夹。没有设置它时，地址变化后可能需要重新扫码。Mac 显示 iCloud 云盘可用，不代表手机已经选好了文件夹。Connect 和固定的外部地址不需要这套恢复机制。

## 任务完成通知

Yachiyo Connect 支持在任务完成后通知 iPhone。Connect 服务和两端应用都需要支持推送。

- 在电脑的 **设置 → 通用** 中保留任务完成通知。
- 在 iPhone 上允许通知。可以通过 Yachiyo Remote 的 **Settings → Notifications**（设置 → 通知）开启，或进入系统通知设置。
- 修改通知权限后，让手机重新连接电脑。

通知会显示对话标题。点击后，会打开配对电脑上的对应对话。运行失败或取消时不会发送完成通知。应用在前台时不显示通知横幅。推送不会唤醒休眠的电脑，也不会让任务改在手机上运行。

聊天内容在手机和电脑之间加密传输，经过 Connect 或 Cloudflare 时也一样。**推送通知单独处理：Connect 和 Apple 可以看到对话标题和投递所需的信息。** 推送内容不包含聊天正文、模型输出或附件。

## 取消配对或关闭远程访问

在电脑的 **设置 → 远程 → 已配对的手机** 中，找到手机并点击**取消配对**。手机会立即断开，之后需要新配对码才能再次连接。在 iPhone 的设备列表中删除电脑，只会删除手机本地的记录；撤销访问权限需要在电脑上操作。

要停止所有远程连接，关闭**远程访问**并保存，已有配对记录会保留。要移除应用管理的 Cloudflare 隧道，使用 [`yachiyo remote tunnel uninstall`](/zh/docs/cli/remote/)。这个命令会保留远程服务，局域网或外部地址仍可能可用。

## 排查问题

| 现象                           | 检查什么                                                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| 无法点击**显示二维码**         | 开启远程访问并保存。Connect 需要显示已连接；其他方式需要可用的连接地址。                                                        |
| Connect 激活失败               | 检查邀请码是否有效、是否过期，以及电脑能否连接服务。激活和开启远程访问是两个步骤。                                              |
| 手机不接受配对链接             | 生成新链接。使用**复制链接**，不要复制服务地址。如果提示协议版本不支持，更新两端应用。                                          |
| 快速隧道无法启动               | 检查是否已安装 `cloudflared`。如果存在 `~/.cloudflared/config.yaml`，改用命名隧道，不要删除已有配置。                           |
| 已显示地址，手机却连不上       | 确认电脑没有休眠、八千代正在运行，再用蜂窝网络测试。已有域名或仍在运行的 `cloudflared` 进程不能证明隧道可达。                   |
| 隧道重启后手机离线             | 检查 Mac 和 iPhone 的恢复文件夹，或生成新配对码。Windows 需要固定地址或重新配对。                                               |
| Mac 合盖后断开                 | **接电源时保持唤醒**防止应用被挂起，不会覆盖系统休眠或合盖休眠。                                                                |
| 提示明文凭据模式不支持远程访问 | 使用加密凭据并解锁系统密钥存储，然后重启桌面应用。                                                                              |
| 收不到完成通知                 | 检查是否使用 Connect、桌面通知是否开启、iPhone 是否允许通知。权限变化后重新连接；同时检查专注模式，以及应用和服务是否支持推送。 |

用 [`yachiyo remote status`](/zh/docs/cli/remote/) 查看服务、隧道、配对和连接数量。[`[remote]` 配置参考](/zh/docs/reference/config-toml/#remote)列出了保存的设置与默认值。
